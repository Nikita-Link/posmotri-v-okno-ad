# Посмотри в окно

Учебный проект Яндекс Практикума: CSS для приложения, в котором можно искать и смотреть короткие видео из разных городов.

Репозиторий: https://github.com/Nikita-Link/posmotri-v-okno-ad

## Возможности

- Поиск по названию города и времени суток.
- Выбор видео из списка карточек и загрузка следующей страницы результатов.
- Состояния наведения, нажатия и клавиатурного фокуса.
- Кастомные чекбоксы с сохранением доступности настоящих полей формы.
- Ограничение длинных заголовков и описаний, прокрутка списка.
- Прелоадеры и сообщения об ошибках в пределах соответствующих блоков.

## Технологии и структура

HTML, CSS, Flexbox, псевдоклассы и псевдоэлементы, локальные шрифты Fira Sans Condensed и Oswald. Имена классов следуют БЭМ.

В соответствии с заданием доработан `styles/style.css`. HTML-разметка, скрипт приложения, шрифты и готовые стили прелоадера и ошибки сохранены из стартовых материалов.

- `index.html` — разметка страницы и шаблоны.
- `styles/style.css` — сетка, типографика, формы и состояния элементов.
- `styles/preloader.css`, `styles/error.css` — исходные стили загрузки и ошибок.
- `scripts/script.js` — исходная логика приложения.
- `fonts/` — локальные шрифты.

## Запуск

Откройте `index.html` в современном браузере. Также можно запустить локальный сервер из папки проекта:

```sh
python3 -m http.server 8000
```

Адрес страницы: http://localhost:8000.

Для загрузки настоящих видео нужен доступ к внешнему API Практикума `https://v-content.practicum-team.ru`. При недоступности сервера приложение показывает предусмотренное сообщение об ошибке.

Макет фиксированный: ширина страницы 1200 px, содержимое 1140 px. На больших экранах содержимое центрируется по обеим осям. Мобильная перестройка макета заданием не предусмотрена.
